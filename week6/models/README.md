# Week 6 model artifact

The trained `.joblib` file is intentionally not included in this browser-upload package because it is larger than GitHub's normal browser file-upload limit.

Regenerate it locally from the repository root with:

```bash
python week6/src/week6_model_comparison.py
```

The script will create:

`week6/models/Week6_Best_NextHour_PM25_Model.joblib`
